## Описание

Автоматическая система для точного определения габаритов багажа в режиме реального времени с использованием компьютерного зрения и глубинных камер Intel RealSense. Проект решает актуальную задачу контроля размеров ручной клади в аэропортах, обеспечивая быструю и бесконтактную проверку соответствия багажа установленным нормам.

## Возможности

### Основной функционал
- **Автоматическая детекция багажа** - распознавание чемоданов, рюкзаков и сумок с помощью YOLOv8
- **Удаление людей из кадра** - изоляция только багажа для точных измерений
- **3D реконструкция** - построение объемной модели по данным глубины
- **Точное измерение габаритов** - определение длины, ширины и высоты с точностью до сантиметра
- **Трекинг объектов** - отслеживание нескольких предметов багажа одновременно

### Дополнительные функции
- Веб-интерфейс для мониторинга в реальном времени
- Запись и сохранение данных для последующего анализа
- Визуализация результатов с цветовой индикацией (зеленый - проходит, красный - превышает нормы)
- Экспорт 3D моделей багажа(в процессе разработки)

## Технологии

- **Intel RealSense D435** - стереокамера для получения RGB и Depth данных
- **YOLOv8** - нейросеть для сегментации объектов
- **Open3D** - библиотека для работы с облаками точек и 3D реконструкции
- **OpenCV** - обработка изображений и компьютерное зрение
- **Flask** - веб-фреймворк для интерфейса
- **NumPy & SciPy** - научные вычисления и статистический анализ

## Установка

### Требования
- Python 3.7+
- Intel RealSense D400 series камера (или возможность работы с записанными данными)
- CUDA-совместимый GPU (рекомендуется для YOLOv8)

### Установка зависимостей

```bash
# Клонирование репозитория
git https://github.com/alexmeshr/IntellectSchool2025.git
cd IntellectSchool2025

# Установка зависимостей
pip install pyrealsense2 numpy opencv-python flask ultralytics open3d scipy
```

## Использование

### Быстрый старт

```bash
# Запуск с подключенной Intel RealSense камерой
python app.py

# Откройте в браузере
# http://localhost:5000
```

### Работа с записанными данными

```bash
# Запуск в режиме эмуляции с предзаписанными данными
python app.py --mock --video ../raw_data/rgb_frames/ --depth ./raw_data/depth_frames/
```

### Структура проекта

```
baggage-dimension-system/
├── app.py                    # Flask веб-приложение и API endpoints
├── config.py                 # Конфигурация системы
├── interfaces.py             # Абстрактные интерфейсы
├── camera_manager.py         # Главный менеджер системы
├── realsense_camera.py       # Драйвер Intel RealSense
├── mock_camera.py            # Эмулятор камеры для тестов
├── baggage_detector.py       # YOLO детекция и сегментация
├── baggage_tracker.py        # Трекинг объектов между кадрами
├── depth_processor.py        # Обработка карт глубины
├── frame_processor.py        # Основная обработка кадров
├── dimension_estimator.py    # Оценка габаритов по 3D данным
├── video_recorder.py         # Запись данных
├── templates/
│   └── index.html           # Веб-интерфейс
├── recordings/              # Записанные видео
├── raw_data/               # Сырые данные
└── point_clouds/           # 3D модели багажа
```

### Основные компоненты

1. **Захват данных** (`realsense_camera.py`)
   - Получение синхронизированных RGB и Depth кадров
   - Применение фильтров для улучшения качества глубины

2. **Детекция и сегментация** (`baggage_detector.py`)
   - YOLOv8 для обнаружения людей и багажа
   - Создание масок для каждого класса объектов

3. **Трекинг объектов** (`baggage_tracker.py`)
   - Отслеживание багажа между кадрами
   - Фильтр Калмана для предсказания движения

4. **Оценка габаритов** (`dimension_estimator.py`)
   - Выбор лучшего кадра для измерений
   - 3D реконструкция и вычисление ориентированного bounding box

5. **Веб-интерфейс** (`app.py`)
   - Визуализация в реальном времени
   - API для управления системой
